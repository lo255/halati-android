# حالاتي (Halati) — بداية مشروع Android

هذا مشروع أولي مستقل. لا ينسخ كود أو هوية التطبيق المرفق.

## ملاحظات مهمة
- يطلب من المستخدم اختيار مجلد الحالات لكل تطبيق عبر منتقي مجلدات Android (SAF).
- يحتاج المستخدم إلى اختيار مجلد `.Statuses` الصحيح، وقد تختلف إمكانية الوصول إليه باختلاف نسخة واتساب/الشركة المصنّعة وإصدار Android.
- يعرض الملفات التي يستطيع Android إتاحتها عبر المجلد المختار.
- الحفظ ينسخ الملف إلى `Download/Halati` ويعرض فشل الحفظ إذا لم يكتمل.
- لا توجد بعد معاينة داخلية للصور/الفيديو، أو إعدادات الإعلانات، أو توقيع إصدار النشر.
- لا نعد هذا الإصدار جاهزاً للنشر قبل اختباره على الجهاز وإكمال سياسة الخصوصية ومتطلبات Google Play.

## بناء سحابي من الهاتف
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع محتويات هذا المجلد إلى الفرع `main`.
3. افتح تبويب Actions وشغّل workflow: Build Halati Android.
4. بعد نجاح البناء، نزّل artifact باسم `halati-build`.
5. يحتوي على APK تجريبي وملف AAB غير موقّع للنشر؛ يجب إعداد توقيع release قبل رفعه إلى Play Console.

الحزمة: `com.halati.statussaver`
Target SDK: 36
